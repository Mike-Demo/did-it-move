Did It Move? — long session (Helios, up to 1 hour)

One continuous Helios session anchored on the room photo (super-resolution 4x, so frames arrive at 2560×1536). The page records the stream locally in 5-minute segments that download as they complete — if anything drops, finished segments are already saved. Story beats (candle, portrait, window, chair, mirror, settle) fire automatically, one change at a time. Session cost ≈ $0.0017/sec: 10 min ≈ $1.02, a full hour ≈ $6.12.

Run on a normal home network (WebRTC needs UDP), keep this tab in front and the screen on — the page holds a wake lock. On iPad, allow multiple downloads when asked; segments land in Files → Downloads. A YouTube 4K60 master is a post step from these segments, not the live stream (no Reactor model emits native 4K60).

Server recording: if Helios has recording enabled, the page can pull the full session as one MP4 assembled on Reactor's side — no local recorder downscale. "Grab server recording" fetches it at any point; the page also grabs automatically before disconnecting at the end. Reactor holds the clip for 24 hours. For a full hour the server file may be several GB assembled in browser memory — if the iPad struggles with it, the local segments remain the safety copy.
