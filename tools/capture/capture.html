Did It Move? — burst capture (Reactor, xmax-x2-1)

One event per session. For each: this page connects to Reactor, streams the still room photo as the source video, sets the event prompt, lets it run ~16 seconds, then saves the last 12 seconds as an MP4 download named after the event. The page also records the incoming stream locally the whole time (like a screen recorder, but in-page) and saves that too if the clip request fails — so footage survives a connection that drops mid-generation. Each session costs roughly $0.05–0.08 from the account balance. Sessions are hard-capped: the page disconnects on its own after every event.

Run this on a normal home network (WebRTC needs UDP). Keep the tab in front while a session runs. On iPad: keep the screen on (the page asks for a wake lock), and finished recordings land in Downloads in the Files app.
